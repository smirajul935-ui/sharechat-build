# ShareSocial

ShareSocial is a feature-rich social media and short video sharing community Android application inspired by ShareChat, built natively with Kotlin and Jetpack Compose.

## Features
- **Explore Feed**: Browse trending posts across categories (Trending, Funny, Shayari, Tech, Devotional, Quotes), like, comment, share, and create new posts.
- **Short Videos**: Scroll through vertical short video clips with creator profiles, soundtracks, and engagement actions.
- **Chat & Messaging**: Direct messaging with friends and creators.
- **Profile & Language Settings**: Manage profile stats and choose from multiple regional languages (English, Hindi, Bengali, Telugu, Marathi, Tamil, Gujarati, Punjabi).

## Tech Stack
- Kotlin & Jetpack Compose (Material 3)
- Navigation Compose
- ViewModel & StateFlow State Management
- Gradle Kotlin DSL
